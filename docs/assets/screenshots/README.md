# Screenshots

Real screenshots of a running instance belong in this folder and are embedded in the root `README.md`.

## Capture checklist (on your Mac)

1. Start the app as described in the root README (`scripts/dev_up.sh`).
2. Use a demo template and a demo sheet with made-up names. Never capture real personal data.
3. Save PNGs (about 1600 px wide) with these names:

| File | Screen |
|---|---|
| `overview.png` | Overview (KPI cards, chart, current batch) |
| `templates.png` | Templates list and slot confirmation |
| `wizard.png` | New batch wizard |
| `batch-detail.png` | A running batch (progress, rows table) |
| `history.png` | Batch history |

4. Embed them in `README.md` under **Screenshots**, for example `![Overview](docs/assets/screenshots/overview.png)`.
