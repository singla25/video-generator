Dashboard design notes (for frontend-dev)

Reference: trustvest-dashboard.png (Dribbble, "TrustVest FinTech Dashboard Animation" by Alamin Hossen). Use it for style and layout only. Do NOT copy the TrustVest name, logo, illustrations or any finance-specific content. Our product has its own name and data.

1. Visual style to match

ElementWhat the reference doesOur rule
ThemeLight. White cards on a very light grey pagePage #F6F7F9-ish, cards #FFFFFF
CardsThin 1px light-grey border, ~12–14px rounded corners, almost no shadow, generous padding (~20–24px)Same
Primary colourDeep emerald green for chartsEmerald (~#1E7A5A) as the main data colour
Call-to-actionBright lime-green button ("Send Money")Lime (~#A6E07A) for the main action, e.g. Start batch
Soft accentPale mint fill behind highlighted chart column and pill buttonsMint (~#E6F6EE) for highlights and selected states
Status chipsSmall pill with a coloured dot: green "Active", red "Inactive"Same pattern for row statuses (see §3)
Big numbersLarge bold figure with the decimals in faded grey ($34,680.05)Large KPI numbers; secondary part (like "/ 1,000") in faded grey
TypographyClean geometric sans-serif, medium weights, small grey labelsA geometric Google font (e.g. Outfit, Urbanist or Plus Jakarta Sans) + Noto Sans Devanagari for Hindi names
IconsThin outline icons (1.5px stroke)Same style (e.g. Lucide icons)
ChartStepped area/bar chart, emerald bars with a fine diagonal hatch pattern, value labels above each column, dashed vertical separators, one highlighted columnSame look for "Videos generated"
DividersHairline separators, lots of white spaceSame
Motion (from the Dribbble animation)Numbers count up, bars grow in, smooth hoversSame, but respect "reduce motion" settings

3. Mapping the reference to our screens

Column labels ("Payment Initiatives $10,120")Per-period counts ("Mon · 1,240 videos")
"Transfer Calculator" side panelCurrent batch panel: progress ring, ETA, completed/failed counts, Pause / Resume / Retry failed, main lime button

Received / Send chipsCompleted (green) · Processing (blue) · Queued (grey) · Failed (red) · Skipped (amber)
"This Month ▾" dropdownsPeriod filter and status filter
"Try ai Agent" / "Earn $50" pillsNot needed. Use one + New batch pill instead
Sidebar MENU / GENERALMENU: Overview, Batches (Running, Completed, Failed), Templates, History, Security (audit log). GENERAL: Settings, Help

4. Our-product additions (not in the reference)

  • The AI-label / consent status badge on each template card (consent ✓ / missing).
  • A security alert banner when the audit log has a SECURITY_LOGIN_THROTTLED event.
  • The 4-step New batch wizard (upload → map columns & validate → mark slot & preview → output folder & start), in the same card style.
  • Every screen has loading, empty and error states in the same visual language.
  • Hindi text must render correctly anywhere a name appears.
