Plan: docs/plans/better-name-detection.md. Test files: tests/unit/name_detection/, tests/unit/infra/test_name_match_setting.py, tests/integration/api/test_name_candidates.py. Only made-up words; the labelled pair list is tests/unit/name_detection/name_pairs.py.

Names chosen where the contract was open

  • Service: candidates leave the service only through the API, so service behaviour is tested through

the analyse route (POST templates, id, analyse) with the real service, a real database and a fake STT. The developer may add an internal method; tests do not call it.

  • Analyse response gains candidates: [{text, start_s, end_s, closeness, confidence}] (max 3,

closeness and confidence rounded to 3 decimals). GET has no candidates or an empty list.

  • Script loader: loader(weights_dir: Path) -> model where the model has faster-whisper's

transcribe(path, **kw) -> (segments, info); main(argv, *, loader=...) -> int (exit code). Messages for exit code 2 go to stderr and contain the missing path; the table goes to stdout, one row per size starting with the size name, with a header naming closeness and memory.

  • Fake STT (tests/fixtures/doubles.py) records hints.
