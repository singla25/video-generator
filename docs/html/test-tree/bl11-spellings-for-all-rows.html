Store portin vidgen.ports.rows: MissingSpelling(row_id, row_number, name) (frozen dataclass, name decrypted); SpellingStore.rows_missing_spoken_name(batch_id, after: int, limit: int) -> list[MissingSpelling] (QUEUED, no spoken name, row_number > after, ascending, batch must exist) and SpellingStore.set_spoken_name(row_id, spoken) -> bool (encrypts into spoken_name_enc; compare-and-set: only if the row is still QUEUED and has no spoken name; True when stored). Both implemented on SqlRowStore
TriggerBatchFlow.preview_rendered (via BatchService) calls ctx.queue.enqueue_spellings(batch_id) after the commit when ctx.transliterator is not None; a queue error is caught and logged by error type, the preview stays READY. Not on preview_failed, not for a deleted batch

Filler rules: pages by cursor after = last row_number of the page (blank results stay missing, so the cursor must move on); blank/None result = skipped; a lost compare-and-set = skipped; an exception from transliterate or set for one row = failed plus a log record with the error type only; release() is called in a finally (the transliterator may lack it: call only if present); no name or spelling in any log record; a store error that is not per-row propagates after release.
