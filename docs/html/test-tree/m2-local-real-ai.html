Test tree: M2-local real AI (AI_MODE switch + real adapters)

Plan: docs/plans/m2-local-real-ai.md. Tests: tests/unit/ai_local/. All real adapters are tested with stubbed models injected through a loader(weights_dir) -> model seam. No torch, weights or network in default or CI runs. Real-model tests carry @pytest.mark.local_ai and run only with RUN_LOCAL_AI=1.

L1b: UI and status contract (tests/frontend/unit/ai-mode.test.tsx, tests/unit/api/test_system_status.py)

API fields assumed (backend-dev adds, frontend-dev consumes):

  • The system status endpoint (GET, session required) gains ai_mode: "fake" | "local" from Settings.ai_mode, independent of Redis and the DB.
  • batch.preview gains optional suggested_spoken_name: string | null, spoken_name: string | null, spoken_name_confirmed: boolean (local mode).
  • POST on the batch preview path confirm-spelling with JSON {spoken_name} stores the human-confirmed spelling.
  • In local mode the API should refuse approve until the spelling is confirmed; the UI test only pins the disabled button.

L10: neutral empty fidelity and lost-queue recovery

Tests: tests/unit/ai_local/test_fidelity_empty.py, tests/unit/services/test_requeue_stuck_rows.py, tests/unit/worker/test_requeue_wiring.py, tests/integration/api/test_stuck_candidates.py.

Expected API (backend-dev creates):

  • fidelity.mean_fidelity([]) returns Fidelity(ssim=1.0, mean_abs_diff=0.0, texture_ratio=1.0) (no ZeroDivisionError).
  • vidgen.ports.batches.StuckRow(batch_id, row_id, kind: "row" | "preview").
  • BatchStore.stuck_candidates(cutoff, after: UUID | None, limit) -> list[StuckRow]: QUEUED rows of RUNNING batches started before cutoff, plus the preview row of DRAFT batches with a PENDING preview; ordered by row_id, keyset paged. Needs no migration (age = batch.started_at).
  • JobQueue.has_live_job(row_id) -> bool (this is what makes a second run idempotent).
  • vidgen.services.requeue.requeue_stuck_rows(open_uow, queue, clock, *, stuck_after_seconds=600, page_size=500) -> RequeueReport(requeued, skipped_live, queue_down).
  • Settings stuck_after_seconds=600, requeue_interval_seconds=300 (both > 0).
  • vidgen.worker.periodic.PeriodicTask(fn, interval_seconds) with start() (first run immediately) and stop(); job errors are logged, never stop the loop. The worker runs requeue at startup and each interval.
