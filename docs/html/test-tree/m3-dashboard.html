Test tree — M3 operator dashboard (F1)

Plan: docs/plans/m3-dashboard.md (UI-AC1 to UI-AC13) · ADR-009 · API: M1 routes in backend/vidgen/api/ · Tests: tests/frontend/ (Vitest + Testing Library + MSW; Playwright skeletons).

Case IDs TT-UI-AC<n>-<P|N|E><m> start each test title. Unit files import the frontend contract below; E2E specs run only when E2E_BASE_URL is set. The tree is generated by tests/frontend/tools/gen_test_tree.py.

Frontend contract (what frontend-dev provides under frontend/src)

ModuleExports and behaviour
App.tsxApp: routes only, needs Router + QueryClientProvider above it. Routes: login, overview, batches running/completed/failed, new batch (query batch=<id> resumes a draft), batch detail, templates, history, security, settings, help, else "Page not found". Any 401 goes to login
config.tsPOLL_INTERVAL_MS = 2000
api/client.tsApiError {status, code, message, retryAfterSeconds?}; apiFetch(path, init?): absolute URL from window.location.origin, X-CSRF-Token from cookie vidgen_csrf on non-GET/HEAD, codes UNKNOWN_ERROR and NETWORK_ERROR, 204 resolves undefined
layout/AppShell.tsxnav "Primary" (MENU, group Batches, GENERAL), header banner with h1, "+ New batch", avatar image, skip link, main#main, data-testid=app-root with data-reduced-motion, security banner
components/StatusChip.tsxStatusChip({status}), data-testid=status-chip, data-tone green/blue/grey/red/amber
components/CountUp.tsxCountUp({value}), en-US digit grouping, immediate under reduced motion
components/RowsTable.tsxRowsTable({batchId, status?}): search, status filter, paging, row actions
pages/*LoginPage, OverviewPage, WizardPage, BatchDetailPage, TemplatesPage, HistoryPage, SecurityPage; labels and test ids are in the header comment of each test file

API additions decided (DD-16/17): POST /batches/inspect-sheet returns headers and a sample for the wizard; GET /batches/{id}/rows?failure_code= filters failures server-side; template cards show a placeholder icon.

Not covered by automated tests: UI-AC1 visual fidelity (Admin sign-off, F7); UI-AC13 coverage and lint gates (CI: npm run test:coverage, tsc, eslint, prettier); hatched chart pixels (recharts is not asserted in jsdom); axe runs in F6 (TT-UI-E2E-A1).
