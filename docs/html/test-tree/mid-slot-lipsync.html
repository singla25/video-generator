Test tree: lip sync starts at the slot, name in the middle (DD-39 part B, task MID-RED)

The lip sync used to start at 0:00 of the template. LipSyncer.sync now takes an optional start_s (default 0.0 = today's behaviour). The lip sync touches only the segment from start_s and the output is spliced back: original 0..start_s, blended frames, original from start_s + frames/25. Face boxes are cached per (template, start_s) through landmark_key.

Test files:

  • tests/unit/ai_local/test_mid_slot_support.py (ML-F, ML-X, ML-A tests on real ffmpeg)
  • tests/unit/ai_local/test_mid_slot_adapter.py (ML-P, ML-N adapter and fake syncer)
  • tests/integration/worker/test_render_row_mid_slot.py (ML-R row pipeline)
