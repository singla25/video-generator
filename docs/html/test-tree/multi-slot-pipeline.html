Test tree: the pipeline runs once per name slot (DD-40, red step)

A template can hold several name slots. The row pipeline makes one voice, then one lip sync pass per slot in ascending order (each pass takes the previous output; the first pass takes no key source, later passes take the template as the face-box key source), then one encode pass per slot in descending order (each pass takes the previous output; only the pass of the first slot gets the real label and writes output, every other pass gets a transparent 1x1 PNG). Stage order is unchanged.

Test files:

  • tests/integration/worker/test_render_row_multi_slot.py (MS-P, MS-N, MS-E: row pipeline with recording doubles)
  • tests/unit/ai_local/test_lipsync_key_from.py (MS-K: the port and the MuseTalk adapter take key_from)
  • tests/integration/worker/test_render_row_multi_slot_engine.py (MS-V: real FFmpeg, slow)
