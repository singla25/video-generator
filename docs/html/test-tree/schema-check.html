Test tree: startup schema check (BL-8)

When the database is behind the code (e.g. migration 0003 not applied) the app shows ONE clear message instead of screens failing with database errors. The app never applies migrations itself.

Assumed names (the developer may rename, tests then follow): AppDeps.schema_reader, vidgen.worker.schema_log.report_schema_at_start(check), SqlSchemaVersionReader(engine), setting schema_check_ttl_seconds.

├── Scenario: classify revisions (tests/unit/domain/test_schema_state.py)
│   ├── ✅ SS-D-P1 equal/behind by 1 and 2/ahead/None -> ok/behind/ahead/empty
│   ├── ❌ SS-D-N1 non-numeric current -> behind (never ok)
