Test tree: spoken suffix after the name (DD-39, task SUF-RED)

The voice says "<name> <suffix>", for example "राजेश कुमार जी". The suffix is set by Settings.spoken_suffix (env VIDGEN_SPOKEN_SUFFIX, default "जी", max 20 characters, "" switches it off) and reaches the row pipeline through RenderConfig.spoken_suffix (default ""). The text is built by the pure function spoken_text(name, suffix). The suffix is not added when the last word of the name already equals it (case-insensitive). A confirmed spoken name (DD-38, D3) is the base for the suffix.
