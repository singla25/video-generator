Test tree: running the backend suite in parallel (pytest-xdist)

Task XD-T1. Goal: pytest -n 4, -n auto and --dist loadgroup give the same pass/skip counts as the serial run. Checks live in tests/unit/meta/test_xdist_isolation.py (static, no Docker/DB).
